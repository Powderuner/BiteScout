**BiteScout is already live.**  
Use the hosted app here: [`https://powderuner.github.io/BiteScout/`](https://powderuner.github.io/BiteScout/).

Find your perfect restaurant match by adjusting:

- **Price range**
- **Minimum rating**
- **Maximum distance**
- **Category tags**

The page will show you matching restaurants (or tell you if there are no matches) based on your preferences. For most users, **just visit the link above—no local setup needed.**
